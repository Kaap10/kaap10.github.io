# Vardhman Gupta's Portfolio & Knowledge Wiki

A minimal, fast, and highly organized personal portfolio and knowledge base built with [Docusaurus 3](https://docusaurus.io/). 

It features a clean developer-centric landing page, a deeply structured blogs wiki with Algolia DocSearch, and a seamless reddish dark-mode aesthetic.

## Live Site
[kaap10.github.io](https://kaap10.github.io)

## Quick Start

```bash
# Install dependencies
npm install

# Start local development server
npm start

# Build for production
npm run build
```

## Features
- **Minimalist Portfolio:** Clean, text-forward landing page highlighting projects and experience.
- **Knowledge Wiki:** Markdown-based blogs structured by DSA, System Design, AI/ML, and Development.
- **Algolia Search:** Lightning-fast, full-text search across all blogs via Algolia DocSearch.
- **Automated Search Crawler:** GitHub Actions automatically crawls and indexes new blogs on every push.
