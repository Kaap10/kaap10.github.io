System Architecture

The 7-Step Walkthrough Architecture

How build-with-ai preserves state across multiple chat sessions and prevents the AI from forgetting earlier architectural decisions.

1
Initialize
Select a template, experience level, and project overview. The `.buildwithai/` workspace is created.
2
Generate Prompt (`next`)
The CLI formats the active step, identifies recommended models and target files, and copies the prompt to your clipboard.
3
Record Decisions (`done`)
Paste the prompt into your AI assistant, review the architectural output, and record the choices.
4
Automatic Context Injection
On subsequent steps, previous decisions are automatically injected into the generated prompt.
5
Inspect and Modify Decisions
View stored decisions or update any value directly using dot-notation.
6
Track Progress
View project progress bar, active step, and completed step checklist.
7
Export Documentation
Generates standardized documentation (README, BUILD_LOG, CONTEXT) from your build history.

Core Engineering

Engineered for Developers Who Value Quality

Built from the ground up with local-first reliability, complete data sovereignty, and deterministic output.

Zero API Keys & Zero Cost

Runs 100% locally in your terminal. No third-party API accounts or rate limits required.

Universal Model Compatibility

Use with any web interface, IDE plugin, or local model (Claude, ChatGPT, Cursor, DeepSeek, Ollama).

Non-Destructive Guarantee

Operates entirely within .buildwithai/ and never touches or overwrites your application source files.

Solves The Blank Canvas

Asking an AI to "build a whole app" produces monolithic, fragmented code. We break projects into disciplined, sequential phases.

Prevents Context Drift

As the chat progresses, the AI forgets foundational schema and architectural decisions. We interpolate prior choices into downstream prompts.

Enforces Sequential Phases

Prevents jumping directly to UI before establishing data contracts, authentication, or error handling.

CLI Reference

Command-Line Interface

A clean, intuitive command set designed to fit into any modern developer terminal.

Standard CLI Command Set
Run from any project root
$npx build-with-ai
Setup

Interactive launcher displaying active status or starting initialization.

$npx build-with-ai init
Setup

Start setup wizard (template selection, experience level, project concept).

$npx build-with-ai init --template <path|url>
Setup

Load a custom template from a local file path or remote HTTPS URL.

$npx build-with-ai next
Workflow

Generate and copy the prompt for the current step.

$npx build-with-ai next --no-copy
Workflow

Generate the step prompt without accessing the system clipboard.

$npx build-with-ai next --raw
Workflow

Output only the raw prompt string for scripting and CLI piping.

$npx build-with-ai next --json
Workflow

Output complete step metadata as structured JSON.

$npx build-with-ai done
Workflow

Record decisions, archive step logs, and advance to the next step.

$npx build-with-ai back
Workflow

Step back to the previous step without removing recorded context.

$npx build-with-ai jump [step]
Workflow

Navigate directly to a specific step number.

$npx build-with-ai context [key]
State Store

Inspect recorded decisions or retrieve a specific dot-notation path.

$npx build-with-ai set <key> <value>
State Store

Update a decision in context.json from the command line.

$npx build-with-ai status [--json]
Inspection

Display project progress bar, step list, and recorded decisions.

$npx build-with-ai history [step] [--json]
Inspection

Display archived AI responses and step logs.

$npx build-with-ai resume
Inspection

Overview dashboard summarizing active step and next action.

$npx build-with-ai export [--out-dir <dir>]
Artifacts

Generate README.md, BUILD_LOG.md, and CONTEXT.md.

$npx build-with-ai list [-s <query>] [--json]
Blueprints

List and search available templates with step counts.

$npx build-with-ai reset
Maintenance

Remove .buildwithai/ state while leaving project source code intact.
