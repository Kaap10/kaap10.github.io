Zero-API Developer CLI & AI Workflow Engine

Open-source developer CLI guiding engineers through structured development phases with zero-API overhead and persistent local context across any AI model.

AI Model Router

Adaptive LLM selection proxy designed to optimize inference costs through intelligent routing.

Sub-3ms Pareto Traffic Control Room UI with Thompson Sampling RL auto-tuning, dynamically optimizing cost, latency, and quality across OpenAI, Anthropic, Gemini, and local models.

pip install model-router-cli
Architecture Highlight

Engineered an adaptive LLM gateway designed to reduce API costs by dynamically routing prompts based on query complexity with Thompson Sampling RL.

Key Engineering Deliverables
  • •Prompt-Based Model Selection: Analyzes complexity to route between local models and flagship frontier APIs with sub-3ms overhead.
  • •Thompson Sampling RL: Auto-tunes model selection weights dynamically based on real-time feedback loops and latency profiles.
  • •Pareto Cost Optimization: Routes simpler queries to lower-cost models, delivering 40–70% cost savings with zero quality loss.

Terminal Agent

Verify-first autonomous software engineering agent.

An autonomous AI coding agent that plans, modifies, tests, and independently verifies real-world codebases with sandboxed isolation and automatic rollback.

pip install terminal-agent-cli
Architecture Highlight

Implements a verify-first workflow by executing an independent test runner in an isolated sandbox for each code modification.

Key Engineering Deliverables
  • •Autonomous Agent Loop: LLM planning, controlled CLI execution & independent test verification
  • •Independent Verification: Separates code generation from test execution and verification inside an isolated sandbox
  • •Automatic Rollback & Recovery: Classifies failures across 12 categories with SQLite checkpoints and state snapshots

AgentBench

Autonomous AI agent benchmarking framework.

A platform to benchmark, score, and diagnose autonomous AI coding agents on 12 polyglot software engineering tasks using deterministic rule-based scoring and full trace audits.

pip install agentbench-core
Architecture Highlight

Automated multi-task benchmarking of AI agents with deterministic rule-based scoring for fair, non-stochastic comparison.

Key Engineering Deliverables
  • •12 Polyglot Benchmarks: Real-world programming and tool-use scenarios with local Ollama mode ($0 cost) and 5D composite scoring
  • •Deterministic Rule-Based Scoring: Avoids stochastic LLM judging through deterministic rule-based evaluation pipelines
  • •Execution Trace Logging: Complete JSON audit trail with tool calls, timestamps, and microsecond timing
